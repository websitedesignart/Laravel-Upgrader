## Reporting a Vulnerability

If you discover a security vulnerability within this skill, please report it immediately so it can be addressed.

Please send an email to **wesolutionhelp@gmail.com** to report any security issues. 

All security vulnerabilities are taken seriously. You can expect an initial response within **48 hours**, and you will be kept updated on the progress of the fix. Please do not report security vulnerabilities through public GitHub issues.
